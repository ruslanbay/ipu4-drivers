Subject: [RFC PATCH v2 11/12] media: ipu6: Work around IPU4P CSI-2 port 2 timing

Use timing values observed in Windows for the Surface Pro 7 front
camera (CSI-2 port 2, firmware source 7, two-lane D-PHY), including
the lane-count programming order.

Keep the calculated timing path for all other configurations.

Tested on the Surface Pro 7 front camera; other IPU4P systems need
testing.

The Co-developed-by tags will be updated with the contributors' actual
names and email addresses in the final patchset.

+/*
+ * Use fixed timing observed in Windows for IPU4P CSI-2 port 2,
+ * firmware source 7, two-lane D-PHY configuration.
+ */
+static void ipu4p_isys_apply_fixed_2lane_timing(struct ipu6_isys_csi2 *csi2)
+{
+	writel(0, csi2->base + IPU4P_CSI2_RX_DLY_CNT_SETTLE_CLANE);
+	writel(1155, csi2->base + IPU4P_CSI2_RX_DLY_CNT_TERMEN_DLANE(0));
+
+	for (unsigned int i = 0; i < 8; i++) {
+		writel(0, csi2->base + IPU4P_CSI2_RX_DLY_CNT_SETTLE_DLANE(i));
+		writel(1269,
+		       csi2->base + IPU4P_CSI2_RX_DLY_CNT_TERMEN_DLANE(i + 1));
+	}
+}
